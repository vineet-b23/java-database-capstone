# User Stories - Smart Clinic Management System

## Admin
- As an Admin, I want to add doctors to the system so that patients can view and book appointments with them.
- As an Admin, I want to manage system users and monitor clinic operations.

## Doctor
- As a Doctor, I want to view my daily appointments so that I can prepare for patient visits.
- As a Doctor, I want to add prescriptions for patients after an examination.

## Patient
- As a Patient, I want to search for doctors by name or specialty so that I can book an appointment.
- As a Patient, I want to view my booked appointments and medical history.
